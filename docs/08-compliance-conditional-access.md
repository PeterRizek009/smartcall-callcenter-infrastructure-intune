# Compliance + Conditional Access

## Compliance policy (Windows)
Examples:
- Minimum OS version requirement
- BitLocker = required
- Defender = enabled
- Firewall = enabled

## Conditional Access Policies
1) Require MFA for Office 365
2) Require compliant device for Office 365
3) Block legacy authentication

Result:
- Non-compliant devices cannot access corporate apps
- Access is protected with MFA
