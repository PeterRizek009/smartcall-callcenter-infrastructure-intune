# App Management (Intune)

## Call Center Shared Devices (Device-based)
- Microsoft Edge (Required)
- Microsoft Teams (Required)
- Call Center Web App:
  - As a web link or Win32/Store app (Required)
Assign to: CallCenter-Devices group (shared devices)

## Admin/User Devices (User-based)
- Microsoft 365 Apps (Required)
- Outlook, Teams (Required)
- Optional: Line-of-business apps (Required)
Assign to: NonCallCenter-Users group (or per-department groups if desired)

## Best practice
- Shared device apps -> assign to DEVICE group
- User productivity apps -> assign to USER group
